# Модуль NLU (Natural Language Understanding)

Модуль отвечает за понимание естественного языка, маршрутизацию намерений через function calling, извлечение параметров, нормализацию относительных дат и ведение уточняющего диалога.

## Реализованные спринты и функционал

### S0: Прототип Function Calling без БД
- Скрипт: `scripts/prototype_nlu.py`.
- Демонстрирует стабильное извлечение JSON без подключения базы данных.
- Проверяет вызовы инструментов: `create_task`, `create_meeting`, `list_events`, `search_events`, `ask_clarification`.

### S1: Промпты, схемы инструментов и парсинг дат
- Схемы инструментов: `backend/nlu/tools.py`. Поддерживает формат OpenAI Tool Calling (create_task, create_meeting, list_events, search_events, ask_clarification, update_event, complete_event, delete_event).
- Системный промпт: `backend/nlu/prompts.py`. Динамически подставляет текущую дату, день недели и таймзону (Europe/Moscow), задает строгие правила различия задач и встреч.
- Гибридный парсер дат: `backend/nlu/date_parser.py`. Обрабатывает русские относительные выражения ("сегодня", "завтра", "послезавтра", "в пятницу", "через два часа", "на следующей неделе", "до конца недели", "в 10 утра", "в 15:00", "в четверг в 11") с фоллбеком на библиотеку dateparser.
- Корневой интерфейс: `backend/nlu/nlu.py` и `nlu.py` для простого импорта тимлидом.

### S2: Уточняющий диалог и контекст
- Встречи без явного времени: если пользователь говорит "Поставь встречу с Иваном завтра", ассистент не выдумывает время, а переводит диалог в режим уточнения: `ask_clarification(question="На какое время поставить встречу?")`.
- Сквозной контекст диалога: при ответе "В 15:00" ассистент объединяет историю и создает встречу "Встреча с Иваном" на завтра в 15:00.
- Тестовый набор: `tests/test_nlu.py` содержит 47 юнит- и интеграционных тестов, покрывающих все фразы из ТЗ, вариации формулировок и крайние случаи.

### S3: Бонусы
- Перенос событий по контексту: "Перенеси её на завтра" разрешается в `update_event`.
- Завершение задач: "Отметь задачу по отчету выполненной", "Я сделал презентацию" -> `complete_event`.
- Удаление записей: "Удали задачу про презентацию", "Отмени встречу" -> `delete_event`.

### S4: Финальная валидация и демо
- Скрипт: `scripts/demo_nlu.py`.
- Запуск демонстрации 6 ключевых пользовательских сценариев.

## Быстрый запуск

### 1. Запуск юнит-тестов (63 теста NLU)
```bash
pytest tests/test_nlu.py
```

### 2. Запуск прототипа S0 (Function Calling без БД)
```bash
python scripts/prototype_nlu.py
```

### 3. Запуск демо-сценариев
```bash
python scripts/demo_nlu.py
```

## Интеграция с сервисами бэкенда

В `backend/services/dialog_service.py` реализована обработка запросов через `DialogService.handle(req: ChatRequest) -> ChatResponse`, которая автоматически подключена к эндпоинту `/chat` в `backend/api/chat.py`.
