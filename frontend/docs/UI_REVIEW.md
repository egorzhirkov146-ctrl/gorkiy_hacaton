# Проверка обновлённого интерфейса

Проверено в headless Chromium, 21 октября 2026.

- Широкий экран 1440 × 1000: стартовый экран, чат и боковая панель событий.
- Телефон 390 × 844: стартовый экран и список событий, нижняя навигация.
- Узкий экран 320 × 568: отсутствие горизонтальной прокрутки, ввод и отправка.
- Пример запроса подставляется в редактор; отправка создаёт встречу в демо.
- Очистка: отмена сохраняет диалог, подтверждение очищает его.
- Поиск без результатов, сброс фильтров и возврат списка событий.
- Shift + Enter создаёт перенос, Enter отправляет сообщение.
- Ответ API и восстановление истории после перезагрузки (подставные ответы API).
- Ошибка HTTP 503 возвращает текст в редактор и показывает сообщение.
- Отказ в доступе к микрофону показывает ошибку; текстовый ввод остаётся доступен.
- В перечисленных сценариях нет необработанных ошибок JavaScript.

Сборка: npm run build. Тесты: npm test (12 тестов).

## Перед показом на реальном устройстве

Проверить живую цепочку MediaRecorder → /stt → /chat → /tts, качество записи,
поддержку формата аудио вашим backend, воспроизведение и разрешения браузера.
Проверить iOS Safari и Android Chrome с открытой экранной клавиатурой.
Эти проверки требуют устройств и запущенных сервисов; локальные проверки
с подставными ответами их не заменяют.
