# Подготовка к демо GorkyCode — 29–31 октября

## Перед записью

- [ ] Все участники согласовали формат `/stt`, `/chat`, `/tts`, `/events` по README.
- [ ] Backend и frontend развёрнуты на HTTPS или работают на localhost.
- [ ] `.env`: `VITE_DEMO_MODE=false` для настоящего сценария с LLM и STT/TTS.
- [ ] В базе есть тестовые записи и известно, от какого имени/сессии выполняются запросы.
- [ ] Разрешён микрофон, на ноутбуке выбран нужный вход, браузер позволяет воспроизводить звук.
- [ ] Открыты DevTools (Network) на запасном мониторе для диагностики.

## Ручной сценарий (2–3 минуты)

**00:00–00:15. Вступление.** «Это Пульс, ассистент, который управляет задачами и встречами голосом или текстом. Он понимает естественный язык и работает с базой событий».

**00:15–00:35. Голосовое создание.** Нажмите микрофон, скажите «Добавь встречу с командой завтра в 15:00», остановите запись. Покажите распознавание, ответ и карточку созданной встречи. Включите/прослушайте озвучивание.

**00:35–00:55. Текстовый ввод.** Напишите «Поставь задачу подготовить отчёт в пятницу». Покажите подтверждение и сохранение.

**00:55–01:15. Уточнение.** Напишите «Добавь встречу с Иваном завтра». Ассистент должен спросить время. Ответьте «в 11:00», покажите итог.

**01:15–01:40. Получение событий.** Спросите «Что у меня завтра?». Продемонстрируйте список и фильтры «Сегодня», «Неделя», «Все».

**01:40–02:00. Поиск по архиву.** Спросите «Найди задачу про презентацию». Продемонстрируйте поиск по базе CSV (без требования точного совпадения для реальной LLM-версии).

**02:00–02:20. Завершение.** Покажите адаптивную версию через DevTools, объясните архитектуру: browser STT → API/LLM → storage → TTS.

## Контрольные проверки на реальных устройствах

- [ ] Chrome/Edge desktop: микрофон разрешён, запись начинается/останавливается, blob не пустой.
- [ ] Safari/iOS: backend принимает MP4/M4A, если браузер записывает его вместо WebM.
- [ ] Аудио проигрывается после пользовательского клика, ошибки автозапуска не блокируют интерфейс.
- [ ] Enter отправляет текст, пустое сообщение не уходит.
- [ ] Ошибка backend в `/stt` или `/chat` сопровождается понятным уведомлением.
- [ ] После обновления страницы переписка остаётся; задачи сохраняются на стороне backend.
- [ ] На мобильном экране доступны чат, микрофон, кнопка отправки и панель событий через меню.
- [ ] Очистка чата не удаляет задачи.
- [ ] Проверьте запросы «сегодня», «завтра», «послезавтра», «на следующей неделе» и неоднозначный запрос.

> Это план проверки, а не отчёт о выполненном тестировании на перечисленных устройствах.
