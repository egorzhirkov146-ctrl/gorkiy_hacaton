# Голосовой помощник

Локальный прототип для задач, напоминаний и встреч. Интерфейс понимает обычные русские фразы, хранит записи в SQLite и поддерживает текстовый ввод, голосовое распознавание и озвученный ответ.

## Запуск

Нужен Python 3.9 или новее. Дополнительные пакеты устанавливать не нужно.

Для понимания свободных формулировок подключен GigaChat API. В `.env` укажите `Authorization_key`, `Client_ID` и `Scope`; приложение получает краткоживущий токен и кэширует его до истечения срока действия. По умолчанию используется `GigaChat-2-Max`; модель можно сменить через `GIGACHAT_MODEL`. Скопируйте шаблон `.env.example` и заполните его значениями из кабинета GigaChat. `Authorization_key` уже содержит закодированные Client ID и Client Secret, поэтому отдельный `Client_ID` не нужен для запроса API.

При включенном GigaChat API история диалога и список записей (до 100 последних, только названия, даты и типы) отправляются в GigaChat для обработки. История и записи хранятся в `assistant.db`; последние 20 реплик передаются отдельными сообщениями с ролями `user` и `assistant`. Для кэширования контекста GigaChat получает постоянный `X-Session-ID`, сохранённый в той же базе. Не включайте API, если не хотите передавать эти данные внешнему сервису. Не публикуйте `.env`: файл исключен из Git.

```powershell
python main.py
```

Откройте http://localhost:8000. Данные сохраняются в `assistant.db` рядом с приложением.

Для запуска тестов:

```powershell
python -m unittest
```

Для голосового ввода используйте актуальный браузер с поддержкой Web Speech API и разрешите доступ к микрофону. Распознавание речи предоставляется браузером; в зависимости от браузера оно может требовать интернет-соединения. Текстовый ввод доступен в браузере, а обработка запросов выполняется через GigaChat.

## Примеры

- «Напомни мне завтра в 10 утра позвонить Ивану»
- «В пятницу нужно отправить отчет»
- «Добавь встречу с командой завтра в 15:00»
- «Что у меня сегодня?»
- «Какие задачи на завтра?»
- «Найди задачу про презентацию»
- «Когда у меня созвон с Саньком?»
- «Что у меня с Саньком на этой неделе?»

Если для встречи не хватает даты или времени, ассистент уточнит их в диалоге.

## Как устроено

- `main.py` содержит HTTP-сервер, вызов GigaChat и выполнение действий в SQLite.
- `index.html` — страница диалога. Web Speech API в браузере распознает речь и озвучивает ответы.
- `assistant.db` создается автоматически при первом запуске и хранит записи и историю диалога.

Каждое сообщение отправляется в GigaChat через `/v2/chat/completions`. История диалога передаётся в `messages` отдельными сообщениями с ролями `user` и `assistant`; планы и результаты поиска запрашиваются по JSON-схеме через `model_options.response_format`. Все запросы одной локальной истории используют постоянный `X-Session-ID`, чтобы GigaChat мог кэшировать совпадающий контекст. Модель решает, ответить ли напрямую или выполнить одно или несколько действий: создать запись, показать записи за период или найти подходящие записи по смыслу. Приложение только проверяет формат данных и исполняет команды базы данных; понимание текста, дат и поиск по смыслу выполняет модель. Для проверки дат модель получает календарь ближайших дней, а сохранённые события показываются вместе с соответствующим днём недели. Если поиск за период ничего не нашёл, модель дополнительно сверяет запрос со всеми сохранёнными записями, чтобы не пропустить событие из-за ошибки в расчёте даты. Результаты действий возвращаются модели для формирования ответа. Если GigaChat недоступен, приложение сообщает об ошибке и не подменяет ответ локальными правилами. Распознавание речи зависит от реализации браузера.

## Что можно улучшить

Добавить управление статусом задач, перенос и удаление голосом, повторяющиеся события, более глубокий поиск по смыслу и синхронизацию с календарем. Для полностью офлайн-голосового режима можно подключить локальную модель распознавания речи, например Whisper.cpp.
