# Голосовой ассистент для управления задачами и встречами

[![Tests Status](https://img.shields.io/badge/tests-89%20passed-brightgreen.svg)]()

Прототип русскоязычного голосового ассистента, разработанный в рамках хакатона. Позволяет пользователю управлять личными задачами, напоминаниями и встречами с помощью естественной речи и текста.

---

## 🌟 Ключевые возможности

1. **Создание задач и напоминаний**:
   - «Напомни мне завтра в 10 утра позвонить Ивану»
   - «В пятницу нужно отправить отчет»
   - «Поставь задачу купить билеты до конца недели»
2. **Создание встреч (с обязательным временем)**:
   - «Добавь встречу с командой завтра в 15:00»
   - «В четверг в 11 у меня встреча с дизайнером»
3. **Уточняющий диалог при нехватке времени**:
   - Пользователь: «Поставь встречу с Иваном завтра»
   - Ассистент: «На какое время поставить встречу?»
   - Пользователь: «В 15:00» -> встреча сохраняется на завтра в 15:00.
4. **Просмотр расписания и планов**:
   - «Что у меня сегодня?», «Какие планы на сегодня?», «Покажи мои встречи на сегодня», «Какие задачи у меня на завтра?», «Что запланировано на эту неделю?»
5. **Семантический и нечеткий поиск старых записей**:
   - «Найди задачу про презентацию»
   - «Когда у меня была встреча с Иваном?»
   - «Я когда-то ставил задачу по договору, найди ее»
   - Поддерживает морфологический стемминг русских окончаний, словарь синонимов (договор = контракт, презентация = слайды, встреча = созвон) и нечеткое соответствие.
6. **Контекстное управление и бонусы**:
   - Перенос событий по контексту диалога («Перенеси её на завтра», «Сдвинь на 16:00»)
   - Завершение задач голосом («Отметь задачу по отчету выполненной», «Я сделал презентацию»)
   - Удаление записей («Удали задачу про презентацию», «Отмени встречу»)
   - Автоматическая проверка конфликтов встреч (предупреждение о наложениях).
7. **Голосовой конвейер**:
   - STT: faster-whisper / Vosk / аудио-конвертация ffmpeg.
   - TTS: потоковый и файловый синтез Microsoft Edge TTS (русские нейросети Svetlana/Dmitry) с автопереключением на gTTS.
8. **Веб-интерфейс**:
   - Встроенный интерактивный веб-UI с кнопкой микрофона, аудиоплеером ответов и живой доской задач.

## 🚀 Инструкция по запуску

### Вариант 1: Быстрый запуск через Python / uv (Рекомендуется)

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/egorzhirkov146-ctrl/gorkiy_hacaton.git
   cd gorkiy_hacaton
   ```

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   # или с помощью uv:
   uv pip install -r requirements.txt
   ```

3. Заполните базу данных тестовыми записями из ТЗ:
   ```bash
   python scripts/seed.py
   ```

4. Запустите сервер:
   ```bash
   uvicorn backend.main:app --host 0.0.0.0 --port 8000 --reload
   ```

5. Откройте в браузере:
   - Веб-интерфейс: [http://localhost:8000](http://localhost:8000)
   - Интерактивная документация Swagger: [http://localhost:8000/docs](http://localhost:8000/docs)

---

### Вариант 2: Запуск через Docker Compose

```bash
docker-compose up --build -d
```
Сервер будет доступен по адресу: `http://localhost:8000`.

## 💡 Принятые самостоятельные решения

1. **Двухуровневая архитектура понимания (Hybrid NLU)**:
   - При наличии API-ключа OpenAI/GigaChat/YandexGPT запросы обрабатываются через OpenAI Tool Calling API с моделью GPT-4o-mini.
   - Встроен детерминированный высокоскоростной локальный экстрактор (`_offline_extract`), гарантирующий моментальную работу системы без внешних задержек сети и расходов токенов в тестовом окружении.
2. **Семантический поиск на основе русской морфологии и словаря синонимов**:
   - Реализован алгоритм с нормализацией падежей, тематическим словарем терминов (договор/контракт/соглашение, презентация/слайды/питч, встреча/созвон/митинг) и нечетким расстоянием сходства строк.
3. **Детекция конфликтующих встреч**:
   - При создании встречи в окне 45 минут от уже запланированной встречи ассистент предупреждает пользователя, сохраняя запись.
4. **Отказоустойчивый синтез речи (TTS Resilience)**:
   - При сетевых сбоях с Edge-TTS поток моментально и прозрачно для пользователя переключается на локальный буфер gTTS.
